## 官方业务示例

[macula-samples](https://github.com/macula-projects/macula-samples) 是官方单仓业务样例，展示 Admin → Gateway → BFF → Feign → Service 的分层调用，包含应用管理、基础能力、开放接口与第三方系统集成。按[创建示例平台](/docs/latest/04_devmanual/创建应用平台/)获取，按[创建示例服务](/docs/latest/04_devmanual/创建服务模块/)完成一项业务改动。

## 组件运行示例

[macula-boot-examples](https://github.com/macula-projects/macula-boot/tree/main/macula-boot-examples) 用于验证框架与组件，入口见[快速开始](/docs/latest/00_introduce/快速开始/)。Consumer、Gateway 和 Provider 演示调用链，不等同于完整业务系统。

## 平台实现

[macula-cloud](https://github.com/macula-projects/macula-cloud) 提供 IAM 与平台管理，Admin 与后端同仓维护。业务应用通过平台凭据、用户菜单和权限能力接入，见[首次接入](/docs/latest/04_devmanual/首次接入macula-cloud/)。

以上为可核对的开源项目案例，不作为生产客户名单或部署规模证明。
