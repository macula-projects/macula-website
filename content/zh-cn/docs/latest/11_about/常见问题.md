## Parent 或 Starter 无法解析

latest 是开发快照，不是已发布稳定版。先核对网络、仓库配置及版本，再按[依赖基线](/docs/latest/00_introduce/概述/#依赖基线)在 Boot 根目录安装完整制品。仅安装 Archetype 不会安装所有 Starter，业务版本也不等于模板版本。

## 已改 .env，但 IDE 服务仍连接旧地址

Java/IDE 不自动加载 `.env`；将变量设置在运行配置，或使用已核对的 profile。Compose 与 Vite 的读取方式不同，重新构建前端后公开变量才会更新。详见[示例配置](/docs/latest/04_devmanual/模块说明/#示例配置)。

## 登录失败、菜单为空或下游 401

依次核对 IAM Client、应用 AK/SK、Cloud endpoint、System Redis 和应用 Gateway JWK。这几组配置不可混用。回调/Origin 精确匹配，租户、应用归属与用户角色需一致。详见[首次接入](/docs/latest/04_devmanual/首次接入macula-cloud/#5-验证结果与失败定位)。

## 为什么看到菜单仍无权调用接口

前端菜单权限、网关 URL 权限与后端方法/资源权限是不同检查点。用真实身份验证后端规则，不通过增加匿名路径规避拒绝。参见[安全架构](/docs/latest/00_introduce/安全架构/)。

## 启动正常却看不到链路和指标

普通本地 profile 默认关闭 OTLP 网络导出。核对导出开关、Collector 地址及协议、采样率、资源标签与网络；不要将 `localhost` 从宿主机配置原样复制到容器。详见 [Observability](/docs/latest/01_services/生产准备/observability/)。

## 数据库迁移校验失败

先备份并检查历史版本与脚本校验和，不修改已执行迁移、不清空历史表。新增迁移修正数据；恢复和回滚按[服务部署](/docs/latest/05_ops/服务部署/)执行。

## 如何报告问题

附分支、提交、运行方式、脱敏配置、复现步骤和错误堆栈，标明是否依赖外部服务。提交路径与验证规则见[贡献规范](/docs/latest/11_about/贡献规范/)。
