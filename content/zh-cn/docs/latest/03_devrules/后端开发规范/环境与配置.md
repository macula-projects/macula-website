后端配置以 Macula Samples 当前的 `application.yml` 组织方式为例：公共段定义应用结构与配置导入，local 提供 IDE 本地值，docker 覆盖容器差异，共享环境通过 Nacos 管理业务配置。

完整约定、可复制的 YAML 骨架、认证地址与变量说明统一维护在[application.yml 配置规范](/docs/latest/04_devmanual/应用配置/)。

重点区分 Gateway 验证 IAM Token、BFF 访问 Cloud System、非网关服务验证 Samples Gateway JWT 三个方向。Java / IDE、Compose 和 Vite 对 `.env` 的读取方式也分别按该页说明配置。
